Explore the geometry

The horizon sightline grazes a spherical planet. The line to the tangent point is perpendicular to the radius there.

cos θ = R / (R + h)
θ(h) = arccos( R / (R + h) )

Compare two models

The exact equation solves for the unknown radius numerically. The small-angle version provides a handy estimate.

Small-angle estimate—
Δθ = ω · Δt
Δθ = θ(h₂) − θ(h₁)
R ≈ 2(√h₂ − √h₁)² / Δθ²

The baseline value assumes ω = 2π / 86,400 rad/s. The Sun's apparent vertical motion is not generally identical to this rotation rate: it depends on latitude, season and geometry.

Scientific limitations: The model ignores atmospheric refraction, uneven horizons, exact eye heights and timing error. A lower estimated radius does not imply the planet is actually smaller.
