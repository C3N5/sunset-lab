# Publish Sunset Lab as a live website

This repository includes a standalone `index.html` at the root, requiring no build tools.

1. Open **Settings → Pages** on the GitHub repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. After GitHub Pages deploys, visit **https://c3n5.github.io/sunset-lab/**.

If Pages is unavailable or disabled, download `index.html` and open it locally in your browser. No server or npm installation is required.

The GitHub repository being online does **not** automatically mean Pages has been enabled.
